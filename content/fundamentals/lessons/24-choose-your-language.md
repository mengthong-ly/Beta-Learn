## Start from what you want to build

The best way to choose: think about what you'd love to make, then pick the language people use for it.

| You want to build... | Learn |
| --- | --- |
| **Websites** | TypeScript, then React for interfaces, or PHP (with Laravel) for the server side |
| **Phone apps** | Dart, then Flutter |
| **Data and AI** | Python |
| **Games and fast programs** | C++ or Rust |
| **Not sure yet** | Python |

---

## Not sure? Start with Python

If nothing above jumps out, start with **Python**. You've already been using it all through this course, so it'll feel familiar.

It's also a great general-purpose language: it reads almost like English, it's used for everything from automating boring tasks to AI, and it's one of the most popular languages in the world.

> 📝 **Note:** Some courses here build on others. React uses TypeScript, Laravel uses PHP and Flutter uses Dart, so learn the language first, then its framework.

---

## Tips for the road

- **Little and often.** Twenty minutes a day beats a long session once a week.
- **Build something small.** A to-do list, a quiz, a calculator. Real projects teach things lessons can't.
- **Expect errors.** You know how to read them now. They're clues, not failures.
- **Use your new habits.** Read the docs, debug one change at a time, and save your work with Git.

> 🧭 **Scenario:** Sam wants to build a website for her bakery. She picks TypeScript, works through the course, then moves on to React to build the pages.
